# HodoPhilic

HodoPhilic is a full-stack travel and accommodation listing platform where users can discover stays, search destinations, create listings, view locations on maps, and add reviews.

## Features

- User registration and authentication
- Create, edit, and delete listings
- Search listings by location
- Browse listings by category
- Trending listings based on reviews
- Interactive maps with location markers
- Image upload using Cloudinary
- Reviews and ratings
- Tax display toggle
- Responsive design

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- JavaScript
- Passport.js
- Cloudinary
- Leaflet
- OpenStreetMap / Nominatim
- MapTiler
